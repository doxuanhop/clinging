# Video Tools - CapCut Style

Một công cụ chỉnh sửa video đa năng với giao diện hiện đại.

## Cài đặt

1. Cài đặt Python 3.8+ nếu chưa có

2. Cài đặt các thư viện cần thiết:
```bash
pip install -r requirements.txt
```

3. Chạy ứng dụng:
```bash
python main.py
```

## Tính năng

### Video Tools
- ✂️ Trim Video - Cắt video
- 🔗 Merge Videos - Gộp nhiều video
- 🎵 Add Audio - Thêm âm thanh vào video
- 🖼️ Add Image - Thêm hình ảnh vào video
- 📝 Add Text - Thêm văn bản vào video
- 🗑️ Remove Logo/Watermark - Xóa logo (cần thư viện bổ sung)
- ✂️ Crop Video - Cắt xén video
- 🔄 Rotate Video - Xoay video
- ↔️ Flip Video - Lật video
- 📐 Resize Video - Thay đổi kích thước
- 🔁 Loop Video - Lặp video
- 🔊 Change Volume - Thay đổi âm lượng
- ⏩ Change Speed - Thay đổi tốc độ
- 🎯 Stabilize Video - Ổn định video (cần vidstab)
- ⏺ Screen Recorder - Quay màn hình (cần mss)
- 🎤 Text to Speech - Chuyển văn bản thành giọng nói (cần gTTS)

### Audio Tools
- ✂️ Trim Audio - Cắt âm thanh
- 🔊 Change Volume - Thay đổi âm lượng
- ⏩ Change Speed - Thay đổi tốc độ
- 🎵 Change Pitch - Thay đổi cao độ
- 🎚️ Equalizer - Điều chỉnh tần số
- 🔙 Reverse Audio - Đảo ngược âm thanh
- 🎤 Voice Recorder - Ghi âm giọng nói
- 🔗 Audio Joiner - Gộp nhiều file âm thanh

## Lưu ý

- Một số tính năng nâng cao yêu cầu cài đặt thêm thư viện
- Video sau khi xử lý cần click "Save" để xuất ra file
- File xuất được lưu vào thư mục VideoTools_Output trong thư mục người dùng
